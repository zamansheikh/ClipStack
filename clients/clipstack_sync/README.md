# clipstack_sync

ClipStack's Wi-Fi clipboard sync protocol v1 in pure Dart, shared by every
Flutter client. The specification is [`docs/05-lan-sync.md`](../../docs/05-lan-sync.md);
the Mac implementation is in [`ClipStack/Sync/`](../../ClipStack/Sync).

- `DeviceIdentity`: device id and static X25519 key pair.
- `PairingLink`: the `clipstack://pair?…` link shown as a QR code.
- `SyncSession`: one encrypted connection, either role. It handles the
  handshake, `hello`/`pair`, clips both ways, and keep-alive.
- `ResponderPolicy`: what a listening device lets in.

```dart
final session = await SyncSession.connect(
  host: '192.168.1.20',
  port: link.port,
  identity: identity,
  peerStaticKey: link.publicKey,
  pairingToken: link.token, // only when pairing
);
session.clips.listen((clip) => print(clip));
await session.sendClip(ClipMessage.text('hello', origin: identity.device.id));
```

## Command-line peer

For testing a listening device (the Mac app) without a phone:

```sh
dart run bin/peer.dart pair '<clipstack://pair?… link>'
dart run bin/peer.dart send 'some text'
dart run bin/peer.dart listen          # prints received clips as JSON lines
```

## Tests

```sh
dart test
```

These include a byte-for-byte test vector generated by the Swift
implementation, so the two sides can't drift apart silently.
